# 📊 Unemployment Analysis in India (Python Project)

## 🔍 Project Overview
This project analyzes unemployment trends in India using Python.  
The goal is to understand how unemployment rates changed over time, especially during the COVID-19 pandemic.


## 🎯 Objectives
- Analyze unemployment rate data
- Identify trends and patterns over time
- Study the impact of COVID-19 on unemployment
- Explore regional and seasonal variations
- Present insights for economic understanding


## 📂 Dataset
The project uses two datasets:
- unemployment_india.csv
- unemployment_covid.csv

These datasets contain:
- Date
- Region (State)
- Unemployment Rate (%)
- Employment Data
- Labour Participation Rate


## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## 🚀 How to Run the Project

1. Install required libraries:
pip install pandas matplotlib seaborn

2. Run the analysis:
python src/analysis.py


## 📈 Key Insights

- Unemployment rates were stable during 2019.
- A significant spike occurred during April–June 2020 due to COVID-19 lockdowns.
- Peak unemployment exceeded 25%, indicating major economic disruption.
- Gradual recovery was observed after mid-2020.
- Regional variations show uneven impact across states.
- Seasonal trends exist but were overshadowed by the pandemic impact.
